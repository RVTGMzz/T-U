## User design correction locked in
6.7.44.14 misinterpreted the live report `spawned=0/N` as permission to remove Pelipper Mutation minions. That was incorrect. The intended Mutation design remains:
- every Mutant calls 2-4 minions;
- minions are a gameplay feature and must be fixed when missing, not removed;
- every main Mutant gets x3 loot after its final defeat, not only Pelipper Mutants;
- Mutation minions remain reward-suppressed by default unless `MutationMinionsDropLoot` is explicitly enabled;
- Pelipper visible Mutant size stays capped at x2.

## 6.7.44.15 changes
### Minions restored and spawn fallback widened
`Alpha674413MutationMinionSpawnService` no longer coexists with any Pelipper minion-suppression hook. The 2-4 wave generated by `MonsterMutationService` is preserved for all Mutants.

When the original strict safe-spawn pass fails, the fallback now:
- uses the visible `PelipperTown.PokemonNpc` position as the anchor for Pelipper Mutants instead of the hidden Green Slime proxy;
- searches deterministic square rings from radius 2 through radius 8;
- requires map/on-passable tile and no placed object;
- allows harmless terrain such as grass instead of rejecting every `terrainFeatures` entry;
- still rejects obvious blocking terrain types such as Tree/Bush/Stump/Log;
- keeps safe distance from the Farmer and other characters.

Status telemetry:
`Mutation minion spawn fallback: minions=2-4 | attempts=... | resolved=... | rejected=... | pelipperSourceAnchors=... | tilesScanned=... | last=...`

### x3 loot is global to every main Mutant
`Alpha674414PelipperMutantRewardService` is retained as the historical filename/class, but its 6.7.44.15 behavior is now global Mutation reward behavior.

On every successful `MonsterMutationService.TryMutate`, regardless of vanilla/custom/Pelipper origin, Team Up marks the main Mutant with `Ronvotri.TeamUp/MutantLootMultiplier=3`.

When that Mutant finally reaches Stardew's `GameLocation.monsterDrop` path, Team Up repeats the native drop pass two extra times with recursion protection. This means three independent native drop rolls/passes, not cloning one chosen item stack.

Status telemetry:
`Mutant reward: lootX3 | minions=2-4 | scope=all-mutants | marked=... | dropHooks=... | dropCalls=... | extraDropPasses=... | errors=... | last=...`
